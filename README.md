# DSA Practice Repository

This repository is built for interview-focused Data Structures and Algorithms practice. It contains Java implementations of common patterns and problem types that frequently appear in coding interviews, especially for companies that expect strong problem-solving fundamentals.

## Purpose

The goal is to reinforce:

- core DSA concepts
- problem-solving patterns
- time and space complexity analysis
- clean interview-style implementations
- confidence with repeated practice and revision

## Coverage

The repo includes solutions and patterns for topics such as:

- arrays and strings
- two pointers
- sliding window
- binary search
- backtracking
- greedy algorithms
- graph traversal
- heap and priority queue
- dynamic programming
- merge intervals
- stack and queue patterns
- linked list problems
- fast and slow pointers

## Folder Structure

- `backtracking/` - recursion and candidate generation patterns
- `binary_search/` - sorted-array search and optimization problems
- `data/` - shared model classes like `ListNode` and `Edge`
- `dp/` - dynamic programming problems and state transitions
- `fast_and_slow_pointers/` - cycle and list-based patterns
- `graph/` - traversal, BFS/DFS, shortest path, islands, etc.
- `greedy_algo/` - locally optimal choices for global solutions
- `heap/` - priority queue and merge patterns
- `kadanes_algo/` - contiguous subarray optimization
- `merge_intervals/` - interval merging and scheduling
- `oop/` - object-oriented programming examples
- `sliding_window/` - fixed and variable window problems
- `stack/` - stack-based validation and parsing problems
- `two_pointers/` - symmetrical, sorted-array, and movement patterns
- `temp/` - scratch/problem experiments

## How to Use This Repo

1. Pick a topic based on your weakest area.
2. Read the problem statement and understand the pattern before coding.
3. Try to solve it on your own before viewing the implementation.
4. Validate the logic with sample inputs and edge cases.
5. Review complexity and compare alternatives.
6. Revisit older problems regularly to retain concepts.

## Interview Mindset

When practicing here, focus on:

- identifying the pattern quickly
- choosing the right data structure
- explaining the approach clearly
- writing readable, well-structured code
- analyzing complexity before finalizing the solution

## Example

A common interview problem in this repo is merging multiple sorted linked lists using a min-heap. This is a classic priority-queue-based pattern that demonstrates efficient merging with reduced complexity.

## Notes

This repository is meant to support consistent, repeatable DSA practice. It is useful for interview prep, revision, and strengthening pattern recognition across common LeetCode and coding interview problem types.
